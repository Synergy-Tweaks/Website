SynToolkit

A Windows 10 and Windows 11 utility with a live hardware dashboard (CPU, RAM, GPU, uptime), a real-time graph, and a collapsible sidebar for tweaks and tools.

Features

What it includes

Hardware dashboard

Live CPU, RAM, GPU, and uptime readouts.

Real-time graph

Activity graph for quick system glance.

Collapsible sidebar

Navigation that stays out of the way when you need space.

Tweaks tab

Shows what SynergyOS applies, with per-tweak toggles.

Games & audio

Games tab with Discord Rich Presence; audio mixer with remembered per-app volumes.

Drivers & cleanup

GPU driver downloads, power plans, and an uninstaller tab.

Requirements

What you need

  • Windows 10 or Windows 11
  • WinUI 3 runtime (bundled with the installer when provided)
  • Works alongside SynergyOS; not required to use the playbook, but installed by default from SynergyOS 1.7
