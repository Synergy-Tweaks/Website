SynergyOS

An AME Wizard playbook that debloats Windows, reduces telemetry, and applies optional performance and privacy options on a clean install.

Overview

What it is

What it changes

Removes unused components you opt into removing, applies registry and policy tweaks, pauses Windows Update until you resume it, and can install SynToolkit and common game runtimes.

What it does not change

It is not a custom ISO by itself, not a game cheat, and not a rollback-friendly patch. It does not invent FPS gains. Security options that weaken Windows are unchecked unless you tick them.

Compatibility

Requirements

Supported bases (from the SynergyOS README): Windows 10 22H2 and Windows 11 22H2–26H2, including LTSC. Windows 11 26H2 is experimental; 25H2 is the safer current base.

Install

Guide

Follow these steps before you download. Skipping them is the usual source of broken installs.

Anti-cheat: If you play FACEIT or Valorant, do not disable Core Isolation / VBS in the customization options.

  1. Download Windows

    Install stock Windows 10 22H2 or Windows 11 22H2–26H2 (25H2 recommended) with no prior tweaks.

  2. Install updates

    Install all updates, restart so they apply, then continue. Do not pause updates first.

  3. Get AME Wizard

    Download AME Wizard from Ameliorated, unzip it, and launch it.

  4. Drag the .apbx in

    Close browsers, Discord, and other background apps. Drag SynergyOS.apbx into AME Wizard.

  5. Choose options

    Tick only what you use. Leave the four security options unchecked unless you understand the tradeoff.

  6. Wait

    Setup usually takes about 10–15 minutes. The PC restarts when finished.

  7. Update drivers

    Install graphics, chipset, and network drivers after the reboot.

Disclosure

Risks and tradeoffs

Some options reduce Windows security. Disabling exploit mitigations, UAC, VBS/HVCI, or Credential Guard makes the machine easier to compromise and can break anti-cheats or enterprise features. Those checkboxes are off by default. Tick them only if you accept that tradeoff.
Defender and other removals: Older playbook versions offered Defender removal and it caused bugs; that checkbox was removed in 1.7. If you removed Defender on an earlier version, reinstall Windows before applying 1.7. Any choice that strips security software increases risk — that is intentional and on you.

Windows Update is paused until 2038 by the playbook. You can resume updates in Settings, then reopen AME Wizard and choose “Run Again”.

FAQ

Common questions

Can I roll back SynergyOS?

No. There is no supported undo. Reinstall Windows from a stock ISO if you need a clean system again. Back up files first.

Is it safe?

It modifies system components. Download only from official GitHub releases. Review every checkbox. Security options that weaken Windows are optional and off by default.

Does it work with anti-cheat?

Keep Core Isolation and VBS enabled for FACEIT and Valorant. Disabling mitigations machine-wide is a common reason anti-cheats refuse to run.

What about Microsoft Defender?

You can keep Defender. The Defender removal checkbox was removed in 1.7 because it caused bugs. Removing antivirus always increases risk.

Can I apply this over another custom OS?

No. Start from stock Windows with no tweaks applied.

Is a fresh install required?

Yes. Clean stock ISO, updates applied, files backed up.

Does Windows Update still work?

Updates are paused until 2038. Resume them in Settings when you want them, then run the playbook again via AME Wizard if needed.

How do I skip the online account requirement?

During Windows setup, choose “Set up for work or school”, then “Domain join” to create a local account.
