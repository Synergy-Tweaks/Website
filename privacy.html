Privacy policy

Last updated: 2026-11-01. This page covers the website only, not Discord, YouTube, or GitHub.

What this site collects

This static site does not use analytics scripts, advertising trackers, or account logins. We do not set analytics cookies from these pages.

Local storage

If JavaScript is enabled, the site may store a short-lived cache of GitHub release metadata in your browser’s localStorage so download version and size fields update without hitting the GitHub API on every visit. You can clear it with your browser’s site data controls.

Third parties

Links go to GitHub, Discord, YouTube, Microsoft, and Ameliorated. Their privacy policies apply when you leave this site. Optional fetch calls to api.github.com load public repository and release data.

Downloads

Downloading SynergyOS or SynToolkit from GitHub is governed by GitHub and by each project’s license. The playbook and app change your Windows installation; that is separate from this website’s privacy practices.
